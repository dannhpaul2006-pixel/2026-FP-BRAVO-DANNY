# Cálculo del Total de una Compra
*Nombre del estudiante:* Danny Bravo

## Descripción
Este programa calcula cuánto debe pagar un cliente en una tienda, multiplicando el precio del producto por la cantidad que lleva.

## Cómo funciona
- La función recibe 2 valores: precio unitario y cantidad.
- Realiza la multiplicación y devuelve el resultado.
- Se muestra el total en pantalla.

## Ejemplo
Precio: 15 | Cantidad: 4 → Resultado: El total a pagar es: $60
